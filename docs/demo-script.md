# 3 分钟演示脚本

## 0:00–0:20 开场
"通用 AI 的失败模式都是看起来对。我们做的是把它们限制在'理解与澄清'，
把'正确'交给确定性引擎。"

## 0:20–1:30 阅读模块
1. 选中一句读不懂的话 → 弹出六个困惑标签（**说明：不要求他会提问**）
2. 点「缺前提，逻辑跳了」→ 它不解释，反问"作者默认了什么？"
3. 说半句 → 它把话往前推一步，不重讲
4. 合上书 → 理解体检：哪几个真懂了

**一句话：它不肯直接告诉你。**

## 1:30–2:40 物理模块
1. 粘题目 → 确认卡（绿/黄/红）
2. 步骤面板 + 动画 + v-t 图同步
3. 拖"传送带速度"滑块 2 → 3，共速点提前
4. 拖到临界值，提示"刚好在末端共速"

**一句话：通用 AI 画得像物理，它能告诉你成不成立。**

## 2:40–3:00 收尾
"两个模块共享同一个骨架：模型负责理解，代码负责正确。"
